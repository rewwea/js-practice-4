# Задания с WHILE

## Задание 1. Вывод символов

Пользователь указывает количество символов. Программа с помощью цикла `while` формирует строку из символов `#`.

Например, при вводе числа `5`:

```text
#####
```

Для подсчета количества повторений используется переменная-счетчик.

## Задание 2. Числа до нуля

Пользователь вводит число. Цикл `while` выводит все числа от введенного значения до нуля.

Например:

```text
5 4 3 2 1 0
```

На каждой итерации значение числа уменьшается на единицу.

## Задание 3. Возведение в степень

Пользователь вводит число и степень.

Возведение в степень реализовано с помощью последовательного умножения в цикле `while`.

Например:

```text
Число: 2
Степень: 4
Результат: 16
```

## Задание 4. Общие делители

Пользователь вводит два числа.

Программа перебирает возможные делители с помощью цикла `while`. Если оба числа делятся на текущее значение без остатка, оно добавляется в список общих делителей.

Для проверки используется оператор `%`.

Например, для чисел `12` и `18`:

```text
1 2 3 6
```

## Задание 5. Факториал

Программа вычисляет факториал введенного пользователем числа.

Факториал числа представляет собой произведение всех целых чисел от 1 до этого числа.

Например:

```text
5! = 1 * 2 * 3 * 4 * 5 = 120
```

Вычисление выполняется с помощью цикла `while`.

# Задания с DO WHILE

## Задание 1. Решение примера

Пользователю предлагается решить пример:

```text
2 + 2 * 2 = ?
```

Правильный ответ:

```text
6
```

Цикл `do...while` продолжает запрашивать ответ до тех пор, пока пользователь не введет правильное значение.

Особенность `do...while` заключается в том, что тело цикла выполняется минимум один раз.

## Задание 2. Деление числа

Начальное значение равно:

```text
1000
```

Программа делит его на `2` до тех пор, пока результат не станет меньше `50`.

Также программа подсчитывает количество выполненных делений.

Последовательность:

```text
1000
500
250
125
62.5
31.25
```

Итог:

```text
Полученное число: 31.25
Количество делений: 5
```

# Задания с FOR

## Задание 1. Кратные числа

Пользователь вводит число.

Программа перебирает числа от 1 до 100 и выводит только те значения, которые делятся на введенное число без остатка.

Например, при вводе `20`:

```text
20 40 60 80 100
```

Для проверки кратности используется оператор `%`.

## Задание 2. Каждый четвертый элемент

Пользователь вводит минимальное и максимальное значения диапазона.

Цикл `for` начинает работу с минимального значения и увеличивает счетчик на `4` после каждой итерации.

Например:

```text
Минимум: 10
Максимум: 30

Результат:
10 14 18 22 26 30
```

## Задание 3. Простое число

Пользователь вводит число.

Программа проверяет, является ли оно простым.

Простым считается натуральное число больше 1, которое имеет только два делителя:

- 1;
- само число.

Для проверки программа перебирает возможные делители. Если число делится хотя бы на одно из них без остатка, оно не является простым.

Например:

```text
7 → простое число
8 → не простое число
```

Для досрочного завершения цикла после обнаружения делителя используется оператор `break`.
